Telco Churn Analysis 📊

This project analyzes telecom customer churn using Power BI and Python.  
It covers customer behavior, service usage, and churn prediction using a machine learning model.

📁 Files Included
- `Telco_Churn_With_Predictions.csv` – Cleaned dataset with churn probabilities
- Power BI dashboards – Customer Insights, Revenue & Risk, and Churn Prediction
- `telco_churn_prediction.py` – Python script for predictive modeling
- Word report with detailed analysis and insights

 🧠 Tools & Skills
Power BI | Python | Pandas | Matplotlib | DAX | Data Cleaning | Predictive Modeling
