# Deloitte Data Analytics Virtual Experience

## Daikibo Telemetry Data Analysis

This project was completed as part of the Deloitte Data Analytics virtual experience on Forage.

### Objective

The task was to analyse telemetry data collected from Daikibo's four factories and answer:

1. Which location had the most machine downtime?
2. Which machine types broke down most often at that location?

### Tools Used

- Tableau
- Data Analysis
- Data Visualization
- Calculated Fields

### Dashboard

The dashboard contains:

- Down Time per Factory
- Down Time per Device Type
- Interactive factory filtering

### Key Finding

Daikibo Factory Seiko recorded the highest downtime.

The dashboard shows approximately **480 minutes of unhealthy/downtime status** for Daikibo Factory Seiko.
